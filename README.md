# Hi, I'm Rameswar Bhattacharjee 👋

Computational chemist working at the intersection of **quantum chemistry and machine learning**. I build predictive, interpretable models of molecular materials and catalysts — from high-throughput DFT data and physics-based descriptors to validated ML models.

Research Assistant Professor, Department of Chemistry, Georgetown University.

### What I work on
- **Molecular machine learning** — descriptor-based models (Extra Trees, MLP) and ML interatomic potentials
- **Electronic-structure theory** — DFT, TDDFT, broken-symmetry and multireference methods
- **Organic electronic and radical materials** — π-stacking, pancake bonding, conjugated polymers
- **Catalysis** — reaction mechanisms in homogeneous and heterogeneous systems

### Featured project
**[Machine learning for π-stacked radical dimers](https://github.com/rameswariacs/BLA-ML-publication)** — 2,582 DFT geometries, 19 descriptors, four predicted electronic properties (test-set R² 0.91–0.98).
*J. Chem. Inf. Model.* 2026 · [doi:10.1021/acs.jcim.6c02583](https://doi.org/10.1021/acs.jcim.6c02583)
